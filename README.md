# OmniVoice AI

Real-time translation calls & chat (Next.js).

## Quick start

```bash
npm install
npm run dev
```

Without backend env vars the app runs in **local demo mode**. For production (Supabase auth, Stripe, LiveKit), follow **[SETUP.md](./SETUP.md)**.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm start` — serve production build
